# Shohel Ahmed — One-page Academic Website with Sticky Section Tabs

This version keeps the full academic website on one page.

## Top navigation
The sticky top tabs are:
- About
- Research
- Publications
- Teaching
- Talks
- Awards
- Contact

Clicking any tab smoothly scrolls to that section.

The active tab automatically highlights while you scroll.

On phones/tablets, the navigation remains visible and can be swiped horizontally.

## Content decisions
- Manuscripts in preparation are omitted.
- Academic & community service is omitted.
- Published/accepted and under-review publications remain.
- The research section uses interactive expandable cards.
- Publications remain searchable and filterable.
- Light/dark mode, animated statistics, and scroll progress remain included.

## Easy editing
Open `index.html` and search for:

`EASY-EDIT CONTENT AREA`

Most research and publication updates can be made there.


## Headshot placement
The homepage now places `headshot.jpg` in a compact portrait card at the **top-right of the hero section**.

Your GitHub repository already contains `headshot.jpg`, so replacing only `index.html` there will use the existing photo automatically.
